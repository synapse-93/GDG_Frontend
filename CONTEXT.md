## Mandatory Submission Items
1. Public GitHub repository with working frontend code (Next.js + Tailwind CSS).
2. Live deployed website link (Vercel).
3. Responsive layouts across mobile (`375px`), tablet (`768px`), and desktop (`1440px`) for Home, Events (including Event Detail), and Team.
4. Both Light and Dark themes with readable contrast.
5. `README.md` containing: brief description, desktop & mobile screenshots, technologies used, setup instructions, live demo link, and open-source credits.
6. `DESIGN_NOTE.md` (1 page maximum) explaining chosen style, color and typography rationale, and adherence to GDG brand guidelines.

## Judging Criteria
1. **Concept & Originality:** Clear, fresh, memorable identity.
2. **GDG Brand Fit:** Consistent use of the four Google colors, respectful logo placeholder with clear space, open developer spirit, and explicit non-Google-product disclaimer.
3. **Usability:** Clear navigation, strong visual hierarchy, smooth mobile and desktop experience.
4. **Visual Craft:** Polish, spacing rhythm, tactile micro-interactions, and 60fps smooth motion.
5. **Accessibility:** Readable contrast, visible focus states, semantic landmarks, and `alt` / `aria-label` attributes.
6. **Feasibility:** Clean, modular architecture ready for the Core Team to extend into About, Resources, FAQ, and Join pages.
